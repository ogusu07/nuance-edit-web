# NuanceEdit Web

**「複雑な技術を、感性のままに。」**

Webブラウザ上で完結動作する、軽量かつ高精度な非破壊レタッチWebアプリケーションです。画像は外部サーバーへ送信されず、WebGL 2.0 / GLSL シェーダーによりローカル環境のみでリアルタイム処理されます。

## 主な機能

- **WebGL 2.0 リアルタイム処理**: 露出（ハイライトクリップガード付き）、ハイライト・シャドウ、コントラスト、色温度・色合い、自然な彩度（スキントーン保護）、明瞭度、フィルム粒子
- **クイックニュアンスプリセット（5種）**: 透明感ハイキー / シネマティック・エモ / クール＆モダン / ヴィンテージ・ストリート / ナチュラル・復元
- **ポートレート補正**: 肌トーン・スムース / キャッチライト強調 / スキントーン・ウォーム
- **プロフェッショナル詳細**: 階調・カラー・ディテール調整、Affinity風の楕円被写界深度（ボケ）カーソル操作
- **IDE風マルチタブ & 一時保存**: 調整ごとのスナップショットを別タブへ一時保存し、タブ切替で瞬時に比較可能（`Ctrl+S`）
- **カーソル中心ズーム & 比較機能**: ホイール・ダブルクリックで狙った位置を中心に最大800%拡大、分割比較、`Space` 長押し比較
- **トリミング & 書き出し**: アスペクト比プリセット、構図ガイド、WebP / JPEG / PNG フル解像度書き出し

## ローカル開発

```bash
npm install
npm run dev
```
